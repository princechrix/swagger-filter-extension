
# Swagger Controller Filter - Chrome Extension

This Chrome extension adds a floating sidebar to any Swagger UI page, allowing you to filter controllers (tags) using checkboxes.

## Installation
1. Download the ZIP file and extract it.
2. Go to `chrome://extensions/`
3. Enable **Developer Mode** (top-right)
4. Click **Load Unpacked**
5. Select the extracted folder.

You will now see a tag filter sidebar on any Swagger documentation.
